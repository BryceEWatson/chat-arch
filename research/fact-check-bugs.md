# Fact-check bug ledger

This file is the working list of OPEN findings from the fact-check
loop. Each row is a user-visible claim where the rendered value does
not derive correctly from authoritative data, OR where a demo/stub
value is rendered without the required visual badge.

Severity:
- **BLOCKER** — wrong, on a primary surface, would mislead a casual viewer
- **HIGH** — wrong, but on a less-trafficked surface or behind a click
- **MEDIUM** — stale label / off-by-one / minor rounding
- **LOW** — cosmetic mismatch
